# Pro-Chart → TradingView Parity Roadmap

هدف: رساندن Pro-Chart به «کپی برابر اصل عملکردی» تریدینگ‌ویو (سیب سبز به‌جای سیب قرمز — نه کپی گرافیکی/کپی‌رایتی).

## قوانین ثابت (تغییرناپذیر)
1. هیچ صرافی/بروکری اضافه نمی‌شود.
2. هیچ چیز پاک نمی‌شود؛ فقط ارتقا و افزودن فیچر.
3. کپی‌رایت رعایت می‌شود (کد و دارایی گرافیکی اورجینال).
4. هر اجرای لوپ = یک قدم کوچک، قابل‌تحویل، بدون شکستن build.

## وضعیت پایه (اینونتوری ۲۰۲۶-۰۷-۰۹): ~۷۵٪ پریتی
موجود و کامل: انواع چارت (candle/HA/renko/kagi/PnF/…)، گرید چند-چارتی، جست‌وجوی نماد،
واچ‌لیست با فلگ/سکشن، مقیاس log/percent/indexed/invert/lock، Bar Replay، ابزارهای ترسیم کامل
(fib/gann/pitchfork/position/…)، magnet/lock/clone/stay-mode، دیالوگ اندیکاتور (inputs+style)،
تمپلیت اندیکاتور، ۶۰+ اندیکاتور، آلارم (price/indicator/drawing)+لاگ، Data Window (نسبی)،
اسکرینر، خبر، هات‌کی (۵۰+)، اسکرین‌شات، ذخیره/بازیابی لِی‌اوت، نمااسکریپت (کلون Pine)+
اجرای بار-به-بار، سشن‌های معاملاتی، تایم‌زون (۳۰+)، شمارش معکوس کندل، واترمارک،
حالت‌های کراس‌هیر، موبایل/ریسپانسیو.

## گپ‌های ریز اضافی (فرصت‌طلبانه)
- [x] **خطوطِ آلارم روی چارت** — آلارم‌های قیمتیِ ذخیره‌شدهٔ نمادِ فعلی به‌صورتِ خطِ نقطه‌چینِ کهربایی با زنگوله (🔔) و برچسبِ محور رسم می‌شوند؛ همگام با ساخت/حذفِ آلارم و تعویضِ نماد/سری.
- [x] **برو به تاریخ (Go to date)** — دکمهٔ تقویم در نوار بالا + پاپ‌آورِ انتخابِ تاریخ؛ نزدیک‌ترین کندل را وسطِ دید می‌آورد (setVisibleLogicalRange).
- [x] **مقایسهٔ درصدی (Percent Compare)** — توگلِ ٪ کنار چیپ‌های Compare؛ نمادِ اصلی + مقایسه‌ها روی محورِ راستِ مشترک با حالتِ Percentage نرمال می‌شوند (رفتارِ واقعیِ TradingView). خاموش = هر نماد روی محورِ مخفیِ مستقل (رفتارِ قبلی).
- [x] **نوارِ منتخبِ ابزارهای ترسیم (Drawing Favorites)** — ستاره روی هر ابزار در فلای‌اوت + بخشِ دسترسیِ سریعِ ابزارهای ستاره‌دار در بالای ToolRail؛ ماندگاری در localStorage (bn_toolfavs). کاملاً داخلِ ToolRail، بدونِ تغییرِ صفحه.
- [x] **جست‌وجوی اندیکاتور** — باکسِ جست‌وجوی sticky با autoFocus در منوی اندیکاتورها؛ فیلترِ زندهٔ ۹۰+ اندیکاتور بر اساسِ برچسب/کلید + پیامِ «یافت نشد» (مثلِ دیالوگِ اندیکاتورهای TradingView).
- [x] **تشخیصِ خودکارِ واگراییِ RSI (Divergence)** — ماژولِ divergence.js (RSI وایلدر + pivotها)؛ واگراییِ معمولی و مخفیِ صعودی/نزولی روی چارت با مارکرِ دایره‌ای + توگل (آیکنِ Activity). مکملِ تشخیصِ الگوها.
- [x] **هیستوگرامِ حجم روی پِینِ اصلی** — توگلِ حجم (پیش‌فرض روشن، مثلِ تریدینگ‌ویو): HistogramSeries روی محورِ overlayِ 'vol' در پایینِ ۱۸٪ چارت، رنگِ سبز/قرمز بر اساسِ جهتِ کندل؛ ماندگاری + بازساخت روی تعویضِ سری.
- [x] **خطوطِ روزِ قبل (PDH/PDL/PDC)** — توگل: سقف/کف/بستهٔ روزِ قبل به‌صورتِ خطِ نقطه‌چین با برچسبِ محور، فقط در تایم‌فریم‌های درون‌روز؛ بازمحاسبه روی تعویضِ نماد/تایم‌فریم/سری.
- [x] Crosshair sync بین پِین‌های گرید چند-چارتی (از قبل موجود بود — syncBus)
- [x] **تایم‌فریمِ مستقلِ هر سلولِ گرید** — افزودنِ منوی TF به هر MiniChart تا هر سلولِ چند-چارت تایم‌فریمِ خودش را داشته باشد (مثلِ TradingView).
- [x] **منوی راست‌کلیکِ غنی‌تر** — افزودنِ «کپیِ قیمت» (clipboard) و «بازنشانیِ نما (اتوفیت)» به منوی راست‌کلیکِ چارت.
- [x] **نوعِ چارتِ مستقلِ هر سلولِ گرید** — منوی نوعِ چارت (شمعی/خطی/ناحیه‌ای) در هر MiniChart با بازساختِ سری؛ گرید چند-چارتی حالا مثلِ TradingView نماد+تایم‌فریم+نوعِ مستقل دارد.
- [x] **میان‌بُرهای کیبورد برای فیچرهای جدید** — گروهِ «تحلیل»: Shift+V حجم، Shift+P الگوها، Shift+D واگرایی، Shift+R پروفایلِ حجم، Shift+K خطوطِ روزِ قبل + وصل‌کردنِ settings (Ctrl+,) و symbolSearch (Ctrl+K) که کلیدشان بود ولی اکشن نداشتند. همه در دیالوگِ راهنمای میان‌بُرها هم دیده می‌شوند.
- [x] **Legendِ دائمیِ OHLC** — لِجندِ بالای چارت حالا آخرین کندل (OHLC + تغییرِ٪) را همیشه نشان می‌دهد (نه فقط هنگام hover)؛ با تیکِ زنده و تعویضِ نماد به‌روز می‌شود (مثلِ TradingView).
- [x] **خطوطِ سقف/کفِ بازهٔ دیده‌شده (HH/LL)** — توگل: بالاترین سقف و پایین‌ترین کفِ کندل‌های داخلِ کادرِ دید به‌صورتِ خطِ نقطه‌چین با برچسبِ HH/LL؛ با پن/زوم بازمحاسبه می‌شود.
- [x] **Symbol info / Details — بازهٔ ۵۲ هفته** — افزودنِ بالاترین/پایین‌ترینِ ۵۲ هفته (از ۲۶۰ کندلِ روزانه) به تبِ جزئیات (مثلِ TradingView).
- [ ] Alert بر پایهٔ خطوط ترسیم‌شده با تست هندسی دقیق‌تر
- [x] **خروجیِ داده‌ی چارت به CSV** — دکمه در دیالوگِ تنظیمات؛ کندل‌های بارگذاری‌شده را با هدرِ time,OHLC,volume و زمانِ ISO دانلود می‌کند (downloadBlob؛ فقط داده‌ی محلی).
- [x] **Export/Import لِی‌اوت به JSON** — دو دکمه در دیالوگِ تنظیمات: خروجیِ کاملِ میزِکار (WS_KEY) به فایلِ JSON + ورودی از فایل (با بازخوانیِ صفحه برای اعمال). محلی، بدونِ سرویسِ بیرونی.

## دامنهٔ رسمی (ADR-0002 — ۲۰۲۶-۰۷-۳۰)
دامنهٔ محصول رسماً «بهترین چارتِ فارسیِ کریپتوی LBank و فارکس/فلزاتِ وان‌رویال» است
(`docs/adr/ADR-0002-defensible-scope.md`). مقایسه با جهانِ نمادِ TradingView از این پس معیار نیست؛
پریتی فقط در «رفتار/کیفیتِ رابط» و «درستیِ محاسبات» سنجیده می‌شود.
