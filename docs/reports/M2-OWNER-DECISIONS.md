# تصمیم‌های مالک — پاسخ به سؤال‌های M1/M2            (برای Claudeِ سرورِ مرکزی)

تاریخ: ۲۰۲۶-۰۷-۰۲ — این پاسخ‌ها از طرفِ مالک از طریقِ Claudeِ سمتِ اپ ثبت شده است.

## ۱) شبکه: ✅ Hetzner Cloud Network خصوصیِ داخلی — **مجوزِ صریحِ ساخت با API داده شد**

مالک می‌خواهد ترافیکِ بینِ سرورها داخلی/خصوصی باشد. **این عملیاتِ تغییری (mutating) اکنون صریحاً تأیید شده است** — فقط همین عملیاتِ مشخص:

1. ساختِ شبکه: `POST /v1/networks` → نام `prochart-internal`، رنج `10.10.0.0/16`، سابنتِ `10.10.1.0/24` (type=cloud، zone=eu-central).
2. اتصالِ سرورها: `POST /v1/servers/{id}/actions/attach_to_network` برای: مرکزی، هاب (Po-Chart)، فارکس (CoinePro-FX)، کریپتو (TraydeYar-Bot) — و در صورتِ امکان Win-Base.
   - اتصال بدونِ ریبوت است؛ روی لینوکس‌ها اینترفیسِ خصوصی معمولاً خودکار با DHCP بالا می‌آید (در صورتِ نیاز `hc-utils`). **هیچ سرویسِ موجودی را دست نزن؛ فقط اینترفیس اضافه می‌شود.**
3. بعد از برقراری: سرویسِ `central-auth` را (که الان روی 127.0.0.1:8100 است) روی IPِ خصوصیِ سرورِ مرکزی هم bind کن تا هاب به آن برسد. تغییری در پورت‌های عمومی نده.
4. IPهای خصوصیِ نهایی را در گزارش بنویس تا سمتِ اپ/کانفیگ‌ها استفاده شود.

## ۲) SSH: ❌ ورودِ root با رمز **می‌مانَد**

مالک صریحاً گفت مشکلی با رمزِ root ندارد. `PermitRootLogin` را تغییر نده. (پیشنهادِ سخت‌سازی رد شد — دیگر مطرح نکن مگر خودش بخواهد.)

## ۳) سرورِ ویندوز (Win-Base): ✅ **بررسیِ کامل بشود — مهم**

تصحیحِ مهمِ مالک نسبت به نتیجه‌گیریِ M1: **کارِ اصلیِ کپی‌تریدِ فارکس روی همین ویندوز انجام می‌شود** و کلِ فایل‌هایش هم روی سرورِ فارکس هست. پس Win-Base در مسیرِ زنده است.

- ممیزیِ فقط-خواندنیِ کامل (RDP یا هر دسترسی که مالک بدهد): چه سرویس/EA/اسکریپتی در حالِ اجراست، MT5های نصب‌شده و اکانت‌ها، پورت‌های listen، Scheduled Taskها، ارتباطش با سرورِ فارکس (چه چیزی از کجا می‌خواند/می‌نویسد).
- اسکریپتِ آماده: `scripts/audit/server-audit.ps1`. اگر اعتبارِ RDP نداری، از مالک بگیر.
- خروجی: به‌روزرسانیِ `docs/INFRA-MAP.md` + بخشِ «معماریِ واقعیِ کپی‌تریدِ فارکس» (نقشهٔ M5 باید بر این اساس بازبینی شود).

## یادآوری‌های باز (از گزارش‌های قبلی — هنوز انجام‌نشده توسطِ مالک)
- rotate توکنِ هتزنر، تعویضِ رمزهای root که در چت رد و بدل شد.

## ترتیبِ پیشنهادیِ اجرا
۱) شبکهٔ خصوصی + bindِ auth → گزارش کن، ۲) ممیزیِ Win-Base → گزارش کن (`M2B-REPORT.md` یا ضمیمهٔ INFRA-MAP)، ۳) هماهنگی با سمتِ اپ برای فعال‌سازیِ SSO روی هاب (پچ آماده و خاموش است — `M2-APP-REPORT.md`).
