# M5 — شروع: سیگنال‌ها + کپی‌ترید + لایو تریدِ روی چارت      (قراردادِ مشترکِ دو طرف)

هدف: کلِ توانِ سرورهای کریپتو/فارکس در اپ + اجرای زندهٔ هر دو بازار از روی چارت. تقسیمِ کار و قراردادِ API که هر دو طرف به آن می‌سازند. اگر واقعیتِ سرورها چیزِ دیگری اقتضا کرد، **سمتِ سرور این سند را اصلاح و push کند** — این سند مرجعِ مشترک است.

## تقسیمِ کار
| | سمتِ سرور (زیرساخت) | سمتِ اپ |
|---|---|---|
| ۱ | فیدِ واحدِ سیگنال: خواندن از TradeYar (10.10.1.4) و CoinePro-FX (10.10.1.3) روی شبکهٔ خصوصی → نرمال‌سازی → Redis هاب + endpointهای زیر | تبِ «سیگنال‌ها» (کریپتو/فارکس) با کارتِ حرفه‌ای |
| ۲ | کپی‌ترید per-user: نگاشتِ کاربرِ مرکزی/اپ به سیستمِ کپیِ هر دو سمت (فارکس = رجیستریِ ویندوز/`copy_servers`) | سوییچِ فعال/غیرفعالِ کپی‌ترید برای هر بازار + تنظیمِ ریسک |
| ۳ | مسیرِ اجرای فارکس از اپ: هاب → API فارکس → عاملِ ویندوز (poll 12s) — یا مسیرِ سریع‌تری که سمتِ سرور پیشنهاد دهد | لایو تریدِ روی چارت (درگِ خطوط → شیتِ تأیید → اجرا) برای هر دو بازار |
| ۴ | حلِ اختلافِ «۲۸ پوشهٔ کاربرِ ویندوز vs ۱ حسابِ connected» | — |

## قراردادِ API (هاب — همه زیرِ /academy/bn/، احراز با توکنِ موجود)

### GET `/signals?market=crypto|forex&limit=50`
```json
{ "signals": [{
  "id": "cx-123", "market": "crypto", "symbol": "BTCUSDT",
  "direction": "buy", "entry": 64120.5, "sl": 63100, "tps": [66050, 67200],
  "confidence": 78, "status": "active|hit_tp|hit_sl|expired",
  "source": "tradeyar", "created_at": "2026-07-02T10:00:00Z", "note": "…"
}]}
```
گیتِ tier: free = فقط ۳ سیگنالِ آخر با تأخیر؛ vip/premium = کامل (مطابقِ M3).

### GET `/copytrade/status` → `{ "crypto": {"enabled": true, "risk_pct": 1.0, "balance": …}, "forex": {…} }`
### POST `/copytrade/{market}` body: `{ "enabled": true, "risk_pct": 1.0 }` (پرمیوم-گیت)
### POST `/real-order` (موجود) — کریپتو مثلِ قبل؛ **فارکس**: سمتِ سرور مسیرِ هاب→فارکس→ویندوز را پشتِ همین endpoint بیاورد (`market` از نماد تشخیص داده شود). پاسخ: `{ok, ticket/order_id, filled_price?}`.

## ترتیبِ اجرا
1. سمتِ سرور: endpointهای بالا را روی هاب پیاده/وصل کند (در صورتِ نیاز این سند را اصلاح کند) → گزارشِ `M5-SERVER-REPORT.md` با نمونهٔ پاسخِ واقعیِ هر endpoint.
2. سمتِ اپ: با دیدنِ گزارش، تبِ سیگنال‌ها + کپی‌ترید + لایو تریدِ چارت را می‌سازد → `M5-APP-REPORT.md` + APK.
3. تستِ سرتاسری با مالک (اول با حجمِ خیلی کوچک/دمو).

## ⚠️ ایمنی (قوانینِ مالک)
- هر اجرای واقعی: تأییدِ صریحِ کاربر در UI + سقفِ ریسک. هیچ اجرای خودکاری بدونِ روشن‌کردنِ صریحِ کپی‌ترید توسطِ خودِ کاربر.
- تغییر روی سرورهای زندهٔ کریپتو/فارکس/ویندوز فقط با تأییدِ مالک و بکاپ.
