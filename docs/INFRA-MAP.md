## سرور ۵ — مرکزی (همین سرور) ✅

- **میزبان:** `App-Central-Server` — Ubuntu 24.04.4 LTS، کرنل 6.8
- **منابع:** ۸ هسته / ۱۶GB رم / ۳۰۰GB دیسک (~۱٪ استفاده) — جا برای PostgreSQL مرکزی + سرویسِ Auth کاملاً کافی
- **سرویس‌های در حالِ اجرا:** هیچ سرویسِ کاربردی‌ای نصب نیست؛ **docker نصب نیست** (برای M2 باید نصب شود — با تأییدِ مالک)
- **پورت‌های شنونده:** فقط SSH روی پورتِ **۱۳۶۷** (پورتِ غیرپیش‌فرض — خوب)
- **cron:** خالی. **nginx:** نصب نیست.
- ریپو در `/home/Hub/pro-chart` روی برنچِ `claude/android-apk-project-build-l9a960`
- کاربرِ عاملِ Claude: `Hub` (بدونِ sudo — اصلِ حداقلِ دسترسی رعایت است)

## شبکه / DNS

- **هر دو دامنه پشتِ Cloudflare هستند** (`pro-chart.com` و `fx.trade-future.ir` به IPهای 2606:4700::/32 resolve می‌شوند) → IP واقعیِ سرورها از بیرون مخفی است؛ IPهای واقعی از خروجیِ هتزنر API تکمیل می‌شود.
