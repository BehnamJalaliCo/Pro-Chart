# لاگِ لوپِ پریتیِ TradingView (pro-chart.com)

هدف: کلونِ باوفای بصری/رفتاریِ pro-chart.com نسبت به tradingview.com.
وضعیت: ≈۷۰٪ انجام شده؛ ~۱۰۰۰ گپ/باگِ باقی‌مانده. ریتم: هر ۷ دقیقه، یک batch در هر تکرار.

## قوانینِ سختِ لوپ (هرگز نقض نشود)
- ⛔ هیچ فایل/فیچر/محتوایی حذف نشود — فقط additive/fix. (رفعِ باگِ واقعی مجاز.)
- ⛔ فقط صرافی/بروکرِ LBank (کریپتو) + One Royal (فارکس)؛ نه اضافه‌ی دیگری، نه حذفِ این دو.
- ⛔ لوگو فقط Pro-Chart؛ لوگوی TradingView هیچ‌جا قرار نگیرد.
- ⛔ سرور/DB بی‌جهت تغییر نکند؛ اگر لازم شد فقط additive و بااحتیاط.
- ⛔ ریاضیِ دستیِ اندیکاتور → تستِ عددیِ آفلاین قبل از زنده.
- ⛔ بیلدِ موفق ≠ زنده — همیشه تأییدِ زندهٔ تصویری.
- گفتارِ فارسیِ سلیسِ انسانی؛ متنِ انگلیسیِ TV ترجمه/بازنویسی شود، نه کپیِ عینی.

## Backlog (سطوحِ نیازمندِ کلون — پُر و به‌روز می‌شود)
- [ ] چارت: کراس‌هیر، لجند/status-line، اسکیل‌ها، تولتیپ‌ها
- [ ] ریلِ ابزارِ ترسیم: فلای‌اوت‌ها، تنظیماتِ هر ابزار، context menu
- [ ] دیالوگِ اندیکاتورها + تنظیماتِ هر اندیکاتور (Inputs/Style/Visibility)
- [ ] پنل‌های راست: واچ‌لیست، جزئیات، اسکنر، اخبار، تقویم، آلارم، سیگنال AI
- [ ] تولبارِ بالا: intervalها، نوعِ چارت، ریپلی، تنظیماتِ چارت، چیدمان
- [ ] منوها: راست‌کلیک، تنظیماتِ سراسری، پروفایل/حساب
- [ ] تمِ روشن/تیره: رنگ‌ها، فاصله‌ها، فونت‌ها، حالت‌های hover/active/خالی
- [ ] موبایل/ریسپانسیو
- [ ] گفتار/متن‌های فارسی در کلِ اپ
- [ ] انیمیشن‌ها و ترنزیشن‌ها
