# بخش ۱ — تحقیقِ عمیق روی TradingView (مرجعِ طراحی)

### ۱.۱ معماریِ نموداری
- TradingView دو کتابخانه دارد: **Lightweight Charts™** (متن‌باز، رایگان، همانی که الان داریم) و **Advanced Charts / Trading Platform** (بسته، لایسنسی، UIِ کاملِ سایت). برای «کپی‌برابرِاصل» باید **UIِ خودمان را روی یک موتورِ سبک بسازیم** (نمی‌توان Advanced Charts را توزیع کرد).
- **تصمیم:** ارتقا به **lightweight-charts v5** که **Pane نیتیو (چندپنلی)** دارد + یک **لایهٔ Canvas/SVG رویِ چارت** برای ابزارهای ترسیمِ پیشرفته و تعامل.

### ۱.۲ کاتالوگِ کاملِ ابزارها/فیچرهای TradingView (مرجعِ ما)
**انواعِ چارت:** Candles، Bars (OHLC)، Hollow Candles، Heikin Ashi، Line، Area، Baseline، Step Line، High-Low، Columns، Renko، Kagi، Point & Figure، Line Break، Range.
**تایم‌فریم‌ها:** از ۱s/1m تا ماهانه + سفارشی.
**ابزارهای ترسیم (۵۰+):** خط روند، خطِ افقی/عمودی، کانال موازی، رگرسیون، پیچ‌فورک (Andrews)، فیبوناچی (retracement/extension/fan/arc/time-zone/channel/spiral)، گن (Gann box/fan/square)، الیوت ویو (Impulse/Correction)، اشکال (مستطیل/دایره/مثلث/مسیر/منحنی)، علامت‌گذاری (متن/یادداشت/فلش/تصویر/ایموجی)، ابزارِ اندازه‌گیری (Measure/Price Range/Date Range/Bars Pattern)، Long/Short Position (ابزارِ ریسک/ریوارد)، چنگالِ شیف، خطوطِ روند خودکار.
**اندیکاتورها (۱۰۰+):** MA/EMA/WMA/HMA/VWAP، Bollinger، Keltner، Donchian، RSI، MACD، Stochastic، Stoch RSI، CCI، ADX/DMI، ATR، Ichimoku، Parabolic SAR، SuperTrend، Volume، OBV، MFI، Williams %R، Momentum، ROC، Pivot Points، Volume Profile، Market Profile، و …
**Pine Script:** زبانِ اسکریپتِ TradingView برای ساختِ اندیکاتور/استراتژی/آلارم. ساختار: `//@version=5`, `indicator()/strategy()`, توابعِ سری‌ای (`ta.sma`, `ta.rsi`, `ta.crossover`), `plot()`, `plotshape()`, `alertcondition()`, `strategy.entry/exit`. اجرا روی هر کندل (سری‌محور).
**آلارم‌ها:** بر اساسِ قیمت/اندیکاتور/خطِ ترسیم/خروجیِ اسکریپت → نوتیفیکیشن (وب/ایمیل/پوش/وبهوک).
**واچ‌لیست + اسکنر/اسکرینر:** فهرستِ نمادها با قیمتِ زنده، گروه‌بندی، Screener.
**لِی‌اوت/تمپلیت:** ذخیرهٔ چند چیدمانِ چارت (چنددکی)، تمپلیتِ اندیکاتور، Sync بینِ چارت‌ها.
**Replay + Strategy Tester:** بازپخشِ تاریخی + گزارشِ بک‌تستِ استراتژی (Net Profit/PF/Max DD/Win%/Sharpe).
**تریدینگ از روی چارت:** پنلِ خرید/فروش، Drag سفارش/SL/TP روی چارت، DOM.
**UI:** نوارِ ابزارِ چپ (ابزارِ ترسیم)، نوارِ بالا (نماد/تایم‌فریم/اندیکاتور/تنظیمات/Replay)، پنلِ راست (واچ‌لیست/جزئیات/آلارم)، نوارِ پایین (تب‌های دکی/Stock Screener/Pine Editor)، دیالوگِ تنظیماتِ هر اندیکاتور.

### ۱.۳ وضعیتِ فعلیِ ما (نقطهٔ شروع)
- موتور: `frontend/academy/src/components/Terminal.jsx` با **lightweight-charts v4.2** (بدونِ pane نیتیو).
- چارت: فقط Candlestick + Volume؛ اورلی MA20/MA50/BB (کلاینت)؛ ساب‌پنل RSI/MACD/ATR/Stoch/ADX (سرور).
- ترسیم: فقط ۴ ابزار (افقی/روند/فیبو/مستطیل) روی Canvas.
- بک‌اند: `src/api/routes/academy.py` → `/chart/*`, اندیکاتورها `_ind_*`, workspace، paper-trade.
- داده: TimescaleDB جدولِ `candles` (۱۴ نماد، M5..D1، ~۱.۳۸M کندل از Dukascope).
- **شکافِ اصلی تا TradingView:** بدونِ اسکریپت‌نویسی، بدونِ آلارم، بدونِ واچ‌لیست، ترسیمِ محدود، تک‌نوعِ چارت، بدونِ سفارش‌ازروی‌چارت، بدونِ لِی‌اوتِ چندگانه، بدونِ Real-time stream.

# بخش ۲ — معماریِ بازارنما

```
frontend/academy/src/bazaarnama/
  engine/        ← هستهٔ چارت (lightweight-charts v5 wrapper + pane manager)
  drawings/      ← لایهٔ ترسیمِ پیشرفته (canvas overlay، hit-test، handle-drag)
  indicators/    ← رجیستریِ اندیکاتورها (client) + bridge به اندیکاتورهای سرور
  script/        ← نمااسکریپت: parser → transpiler(JS) → Web Worker sandbox + runtime libs
  alerts/        ← تعریف/ارزیابیِ آلارم
  ui/            ← نوارِ چپ/بالا/راست/پایین، دیالوگ‌ها، واچ‌لیست، Pine-Editor
  store/         ← zustand: chartState, layout, drawings, indicators, scripts
  BazaarNama.jsx ← کامپوننتِ ریشه (قابلِ‌جاسازی در LiveChart/Practice/بخشِ مستقل)
src/api/routes/bazaarnama.py   ← APIِ سرور (لِی‌اوت، اسکریپت، آلارم، اندیکاتورهای سنگین، اسکن)
src/bazaarnama/ (بک‌اند)       ← indicator_engine, script_runtime(اعتبارسنجی)، alert_eval (celery)
alembic: جداولِ layouts / scripts / alerts / watchlists
```

**تصمیم‌های کلیدی**
- **موتور:** lightweight-charts **v5** (pane نیتیو) — مهاجرتِ Terminal فعلی.
- **ترسیم:** لایهٔ Canvas مستقل با مختصاتِ chart-space (مثلِ الان) ولی بازنویسی به یک سیستمِ ابزار/handle/hit-test توسعه‌پذیر.
- **اسکریپت (نمااسکریپت):** نحوِ ساده و آشنا (شبیه Pine/JS سبک)؛ **ترنسپایل به JS** و اجرا در **Web Worker سندباکس** (بدونِ DOM/network) با کتابخانهٔ `ta.*` (sma,ema,rsi,crossover,...)، `plot`, `plotshape`, `alertcondition`, و برای استراتژی `strategy.entry/exit`. خروجی‌ها به موتورِ چارت برمی‌گردند.
- **داده:** همان `candles` + افزودنِ **Real-time stream** (WebSocket یا polling) برای کندلِ زنده.
- **امنیت:** اجرای اسکریپتِ کاربر فقط در Worker، تایم‌اوت، بدونِ دسترسی به شبکه/کوکی؛ ذخیرهٔ اسکریپت در DB با مالکیتِ AcademyStudent.
