## ۱) خلاصهٔ مدیریتی

پنلِ فعلیِ بازارنما (`UserPanel.jsx`) یک صفحهٔ تک‌ستونیِ ساده است: کارت‌های «حساب / اشتراک / اتصالِ صرافی-بروکر / تریدِ واقعی». این کافی است ولی با پنلِ کاربریِ TradingView فاصلهٔ زیادی دارد. هدفِ این سند، بازطراحیِ پنل به ساختارِ **چندتبیِ سایدبار-محور** (الگوی `Settings` در TradingView) است که همهٔ دارایی‌های کاربر (واچ‌لیست، آلارم‌ها، اسکریپت‌ها، لِی‌اوت‌ها، اشتراک، امنیت) را در یک‌جا جمع می‌کند — کاملاً فارسی، RTL، و سازگار با تمِ تیرهٔ موجود.

نکتهٔ کلیدی: بخشِ زیادی از API لازم **همین حالا در `api/client.js` موجود است** (واچ‌لیست، اسکریپت، لِی‌اوت، آلارم، اتصال، رفرال، پرداخت، me، pricing). پس بیشترِ کار «چینشِ UI» است نه بک‌اندِ نو. مواردی که API ندارند با برچسبِ **[نیازمندِ بک‌اند]** مشخص شده‌اند.

## ۲) تحقیق: ساختارِ پنلِ کاربریِ TradingView

### ۲٫۱ منوی کاربر (User Menu — کلیک روی آواتار)
ورودِ سریع به همهٔ بخش‌ها از منوی کشوییِ آواتار:
- نام و آواتارِ کاربر + لینکِ پروفایلِ عمومی
- **Profile** (پروفایلِ عمومی: آیدیاها/اسکریپت‌ها/دنبال‌کننده‌ها)
- **Account and billing** (پلن، صورتحساب، تاریخچهٔ پرداخت، آپگرید)
- **My support tickets**
- **Profile settings** (تنظیمات — صفحهٔ چندتبی)
- **Dark/Light theme** سوییچ
- **Sign out**

### ۲٫۲ صفحهٔ تنظیمات (Profile Settings) — تب‌ها
TradingView تنظیمات را در یک صفحهٔ سایدبارِ عمودی با این بخش‌ها می‌چیند:
1. **Profile / Public profile** — نام نمایشی، یوزرنیم، آواتار، بایو، شبکه‌های اجتماعی، کشور/منطقهٔ زمانی.
2. **Account and billing** — پلنِ فعلی، تمدید/ارتقا، روشِ پرداخت، تاریخچهٔ فاکتورها، کدِ تخفیف.
3. **Privacy and security** — تغییرِ رمز، **2FA** (+ بک‌آپ‌کُد)، کنترلِ «چه‌کسی می‌تواند چت/پیام بسازد»، حذفِ حساب.
4. **Sessions and devices** — لیستِ نشست‌های فعال (مرورگر/اپ/IP/مکان) + «خروج از همهٔ دستگاه‌ها».
5. **Notifications** — تنظیمِ کانال‌های اعلان (ایمیل/پوش/تُست) برای آلارم، کامنت، پیام، فالوِ جدید، خبر.
6. **Connected apps / API** — اپ‌ها و وب‌هوک‌های متصل، توکن‌های API.
7. **Brokers** — حساب‌های بروکرِ متصل برای تریدِ مستقیم از چارت.

### ۲٫۳ دارایی‌های کاربر (در نوارِ ابزارِ راستِ چارت، نه در Settings)
این‌ها در TradingView داخلِ چارت‌اند ولی در پنلِ بازارنما هم می‌توان «نمای مدیریتی» داد:
- **Watchlists** — چند واچ‌لیست، رنگ‌بندیِ نماد، فلگ، بخش‌بندی.
- **Alerts** — سه نوع: قیمتی / تکنیکال (اندیکاتور و الگو و درای‌تول) / واچ‌لیستی؛ + **Alert log** (تاریخچهٔ شلیک)؛ کانال‌های تحویل: تُست/ایمیل/اپ/وب‌هوک/صوت؛ انقضای پیش‌فرض ۲ماه (Premium = نامحدود).
- **Ideas** — چارت‌های منتشرشده + لایک/کامنت/فالو.
- **Scripts** — اسکریپت‌های Pine (در بازارنما: **NamaScript**) شخصی/عمومی + ادیتور.
- **Paper trading & Broker** — حسابِ شبیه‌سازی + حسابِ واقعی.
- **Drawing/Chart layouts** — لِی‌اوت‌های ذخیره‌شدهٔ چارت.

### ۲٫۴ صفحهٔ Account & Billing
- نمایشِ پلن (Free/Essential/Plus/Premium/Ultimate)، چرخهٔ صورتحساب، تاریخِ تمدید.
- دکمهٔ Upgrade/Downgrade، مدیریتِ روشِ پرداخت، تاریخچهٔ فاکتور (دانلودِ PDF).
- لغوِ اشتراک، کدِ تخفیف/معرفی.

> منابع: TradingView Help — Profile Settings، Introduction to Alerts، Features، Pricing (لینک‌ها در پایان).

## ۴) ساختارِ تب‌های پیشنهادیِ پنلِ بازارنما

لِی‌اوتِ کلی: **سایدبارِ راستِ عمودی (RTL)** + ناحیهٔ محتوای اصلی. در موبایل، سایدبار به **تب‌بارِ بالا/کشویی** تبدیل می‌شود.

```
┌──────────────────────────── Header (لوگو · تمِ تیره · خروج) ───────────────┐
│ ┌─ محتوای تب ─────────────────────────────────────┐  ┌─ Sidebar (راست) ─┐ │
│ │                                                  │  │ ▸ حساب            │ │
│ │   <محتوای تبِ فعال>                               │  │ ▸ اشتراک          │ │
│ │                                                  │  │ ▸ اتصالِ حساب      │ │
│ │                                                  │  │ ▸ واچ‌لیست         │ │
│ │                                                  │  │ ▸ آلارم‌ها         │ │
│ │                                                  │  │ ▸ اسکریپت‌ها        │ │
│ │                                                  │  │ ▸ لِی‌اوت‌ها         │ │
│ │                                                  │  │ ▸ اعلان‌ها          │ │
│ │                                                  │  │ ▸ امنیت            │ │
│ │                                                  │  │ ▸ معرفی (رفرال)    │ │
│ └──────────────────────────────────────────────────┘  └──────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

### تب ۱ — حساب (Account)
- آواتار + نامِ نمایشی + یوزرنیم + ایمیل + نوعِ حساب (کریپتو/فارکس).
- ویرایشِ نامِ نمایشی، آواتار (آپلود)، بایوِ کوتاه، منطقهٔ زمانی. *[آپدیت نیازمندِ بک‌اند]*
- تاریخِ عضویت، وضعیتِ تأییدِ ایمیل.
- دکمهٔ «مشاهدهٔ پروفایلِ عمومی» (فاز ۲).

### تب ۲ — اشتراک (Subscription / Billing)
- کارتِ پلنِ فعلی: رایگان/VIP/پرمیوم + تاریخِ انقضا + نوارِ شمارشِ معکوس.
- مقایسهٔ پلن‌ها (ماهانه ۱۵ تتر / سالانه ۲۰۰ تتر) با ✓/✗ فیچرها.
- جریانِ پرداخت: آدرسِ کیفِ BSC + کپی + فرمِ هشِ تراکنش (همان `PaymentForm` فعلی).
- **تاریخچهٔ پرداخت‌ها**: جدولِ تراکنش‌ها (تاریخ/مبلغ/پلن/وضعیت/هش). *[نیازمندِ بک‌اند: `bnBillingHistory`]*
- کدِ تخفیف/معرفی. *[نیازمندِ بک‌اند]*

### تب ۳ — اتصالِ حساب (Brokers / Exchange)
- بر اساسِ `account_type`: کریپتو→`ConnectLbank`، فارکس→`ConnectMt5` (کامپوننت‌های موجود).
- وضعیتِ اتصال + تأییدِ رفرال + دکمهٔ حذف (`bnConnectRemove`).
- هشدارِ گیتِ پرمیوم برای تریدِ واقعی.

### تب ۴ — واچ‌لیست (Watchlist)
- لیستِ نمادهای واچ‌لیست با لوگوی نماد + قیمتِ زنده (`bnPrices`) + تغییرِ درصدی.
- افزودن/حذفِ نماد (دراگ برای ترتیب — فاز ۲)؛ ذخیره با `bnWatchlistSet`.
- چند واچ‌لیست (تب‌های داخلی). *[نیازمندِ بک‌اند برای multi-list]*
- دکمهٔ «بازکردن در چارت» → دیپ‌لینک به `pro-chart.ir/?symbol=...`.

### تب ۵ — آلارم‌ها (Alerts)
- جدولِ آلارم‌ها (`bnAlerts`): نماد، شرط (≥/≤ قیمت)، وضعیت (فعال/شلیک‌شده)، کانالِ تحویل، تاریخ.
- ساختِ آلارم (`bnAlertCreate`) + حذف (`bnAlertDelete`).
- فیلتر بر اساسِ وضعیت؛ نمایشِ **Alert log** (تاریخچهٔ شلیک). *[log نیازمندِ بک‌اند]*
- لینک به پنلِ آلارمِ کاملِ داخلِ چارت (`bazaarnama/AlertsPanel.jsx`).

### تب ۶ — اسکریپت‌ها (NamaScript)
- لیستِ اسکریپت‌های ذخیره‌شده (`bnScripts`): نام، عمومی/خصوصی، تاریخِ ویرایش.
- ویرایش/حذف (`bnScriptGet/Save/Delete`) + «بازکردن در ادیتور».
- گیتِ VIP برای نمااسکریپت (هماهنگ با تسک #238/#8).

### تب ۷ — لِی‌اوت‌ها (Layouts)
- لیستِ لِی‌اوت‌های چارت (`bnLayouts`): نام، تعدادِ پنل، تایم‌فریم، تاریخ.
- بازکردن/تغییرِنام/حذف (`bnLayoutGet/Save/Delete`).

### تب ۸ — اعلان‌ها (Notifications)
- سوییچ‌های روشن/خاموش برای: شلیکِ آلارم، اخبارِ مهم، تأییدِ پرداخت، تأییدِ رفرال، پیامِ پشتیبانی.
- انتخابِ کانال: ایمیل / تلگرام / درون‌برنامه‌ای. *[نیازمندِ بک‌اند: `bnNotifPrefs get/set`]*

### تب ۹ — امنیت (Security)
- تغییرِ رمزِ عبور (با `PwInput` موجود). *[نیازمندِ بک‌اند: `bnChangePassword`]*
- **۲FA** (فعال‌سازی با QR + بک‌آپ‌کُد). *[نیازمندِ بک‌اند]*
- **نشست‌های فعال**: لیستِ دستگاه‌ها (مرورگر/IP/آخرین فعالیت) + «خروج از این دستگاه» + «خروج از همه». *[نیازمندِ بک‌اند: `bnSessions list/revoke`]*
- حذفِ حساب (با تأییدِ دومرحله‌ای). *[نیازمندِ بک‌اند]*

### تب ۱۰ — معرفی (Referral)
- لینکِ رفرالِ کاربر (`bnReferralLink`) + کپی + اشتراک‌گذاری.
- لینکِ ساختِ حسابِ صرافی/بروکر با رفرالِ ما.
- آمارِ زیرمجموعه (تعداد/پاداش). *[نیازمندِ بک‌اند]*

## ۵) معماریِ کامپوننت‌ها (پیشنهادِ پیاده‌سازی)

ساختارِ فایل‌ها (می‌توان همه را در `UserPanel.jsx` نگه داشت یا به پوشهٔ `userpanel/` شکست):

```
UserPanel.jsx              ← رِپوی اصلی: state تب، auth، shell
  ├─ <PanelShell>          ← Header + Sidebar + Content (RTL، responsive)
  ├─ <SidebarNav>          ← لیستِ تب‌ها + آیکونِ lucide + بَج (مثلاً «۳ آلارمِ فعال»)
  ├─ <AuthGate>            ← (موجود) ورود/ثبت‌نام — بدونِ تغییر
  └─ tabs/
       ├─ AccountTab.jsx        ← حساب + ویرایشِ پروفایل
       ├─ BillingTab.jsx        ← اشتراک + PaymentForm + تاریخچه
       ├─ ConnectTab.jsx        ← ConnectLbank / ConnectMt5 (موجود)
       ├─ WatchlistTab.jsx      ← bnWatchlist + قیمتِ زنده
       ├─ AlertsTab.jsx         ← bnAlerts (خلاصه؛ کامل در AlertsPanel)
       ├─ ScriptsTab.jsx        ← bnScripts
       ├─ LayoutsTab.jsx        ← bnLayouts
       ├─ NotificationsTab.jsx  ← سوییچ‌ها [نیازمندِ بک‌اند]
       ├─ SecurityTab.jsx       ← رمز/۲FA/نشست‌ها [نیازمندِ بک‌اند]
       └─ ReferralTab.jsx       ← bnReferralLink + آمار
```

### کامپوننت‌های اشتراکیِ پیشنهادی (UI primitives)
- `<Card title icon>` — **موجود** (در `UserPanel.jsx`)، بازاستفاده.
- `<Tab>` / `<SidebarItem>` — آیتمِ سایدبار با حالتِ active، آیکون، بَج، آنکلیک.
- `<Toggle>` — سوییچِ on/off برای تبِ اعلان‌ها.
- `<DataTable>` — جدولِ ساده برای آلارم/پرداخت/نشست (RTL، tabular-nums).
- `<Badge tier>` — نشانِ پلن (رایگان/VIP/پرمیوم) با رنگِ کهربایی برای پرمیوم.
- `<EmptyState>` — حالتِ خالی («هنوز آلارمی نساخته‌ای») + CTA.
- `<CopyButton>` — منطقِ کپیِ موجود (refUrl/wallet) استخراج‌شده به یک کامپوننت.
- `<ConfirmDialog>` — برای حذفِ حساب/خروج از همهٔ دستگاه‌ها/حذفِ اتصال.
- `<PwInput>` — **موجود**، بازاستفاده در امنیت.
- `<SymbolLogo>` — **موجود** (`bazaarnama/SymbolLogo.jsx`) برای واچ‌لیست.

### مدیریتِ state و مسیریابی
- تبِ فعال در state محلی + همگام با hash مسیر: `user.pro-chart.com/#/account`, `#/billing`, ... (دیپ‌لینک‌پذیر).
- `auth`/`me` در سطحِ `UserPanel` بارگذاری (موجود)؛ هر تب دادهٔ خود را lazy لود کند (مثلاً `WatchlistTab` فقط هنگامِ باز شدن `bnWatchlist` صدا بزند).
- پایداریِ آخرین تب در `localStorage` (`bn_panel_tab`).
- بَج‌های سایدبار: شمارشِ آلارم‌های فعال، وضعیتِ اتصال (سبز/قرمز)، انقضای نزدیکِ اشتراک.

### دسترسی‌پذیری و RTL
- کلِ پنل `dir="rtl"`؛ کدها/هش‌ها/ایمیل/یوزرنیم `dir="ltr"` (الگوی موجود).
- اعداد با `tabular-nums` (هم‌خط با اسپکِ ProChart UI).
- ناوبریِ کیبورد روی سایدبار، فوکوسِ مرئی، `aria-current` روی تبِ فعال.
