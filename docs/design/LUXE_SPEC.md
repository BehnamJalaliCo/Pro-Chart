# LUXE_SPEC — زبانِ طراحیِ واحدِ Pro-Chart (فاز ۱ لوکس‌سازی)

**تاریخ:** ۲۰۲۶-۰۷-۳۰ · **مبنا:** `TV_GAP_REGISTER.md` V-2/V-5/V-6/V-9 + اسکرین‌شاتِ لایو
**اصل:** لوکس یعنی خویشتن‌داری. رنگ = اطلاعات، نه تزئین. جداکنندهٔ مویی، نه قرص. یک سیستم، نه چهار.

این سند **قانون** است؛ ایجنت‌ها مکانیکی اعمالش می‌کنند. هر جا کد با این سند تضاد دارد، کد عوض می‌شود — مگر تغییر، رفتار/قابلیت را بشکند (⛔ حذفِ قابلیت ممنوع؛ فقط بازپوشانی).

## ۲. قانونِ رنگ — قلبِ اسپک

**در حالتِ سکون (idle) کروم تک‌رنگ است.** فقط این‌ها می‌توانند رنگی باشند:
1. **دادهٔ بازار:** اعدادِ قیمت/تغییر (`upText`/`downText`)، کندل‌ها، اسپارک‌لاین، چیپِ BUY/SELL.
2. **CTA اصلی:** حداکثر یک `.btn-primary` در هر دیالوگ + دکمه‌های خرید/فروش (up/down).
3. **امضای برند (تنها استثنا):** دکمهٔ «سیگنال AI» — تینتِ بنفشِ ملایم `rgba(139,92,246,.12)` + آیکونِ `accentAi`. **گرادیانت ممنوع.**

**حالتِ فعال/انتخاب‌شده:** متن/آیکونِ `--pc-accent` یا پس‌زمینهٔ `--pc-accent-tint`. **پرشدنِ آبیِ توپر ممنوع** (جز CTA بالا). چیپِ تایم‌فریمِ فعال: تینت + متنِ accent، نه آبیِ پر.

**ممنوع در سکون:** گرادیانت، قرصِ رنگی، واشِ رنگیِ پس‌زمینهٔ سکشن (مثل کارتِ بنفشِ «حقایق کلیدی» → `pc-card-flat` + فقط آیکونِ رنگی)، نقطهٔ قرمزِ تزئینی، `auto/log` آبیِ پر (→ متنِ ۱۱px، فعال = متنِ accent).

## ۳. قرص → برچسب + مویی

- ردیفِ دکمه‌های هم‌خانواده: دکمهٔ متنی/آیکونیِ شفاف (`.pc-iconbtn`) + جداکنندهٔ گروهِ `.pc-toolbar-sep`. **قرصِ خاکستریِ پرشده فقط برای حالتِ فعالِ خنثی** (`--pc-pressed`).
- `rounded-full` روی کنترلِ مستطیلی ممنوع (فقط آواتار/دایرهٔ واقعی/سوییچ).
- شعاع: کنترل `4px` · پاپ‌آپ `6px` · دیالوگ/کارت `8px`. (`rounded-lg`=8px فقط کارت/دیالوگ؛ کنترل‌ها `rounded` یا `rounded-md`.)

## ۴. اندازه‌ها — بدونِ استثنا

| چیز | مقدار |
|---|---|
| تولبارِ بالا | ارتفاع `40px`، دکمه‌های داخلش `28px`، آیکون `18px` |
| نوارِ فرعی/تب‌ها | `36px` |
| ردیفِ واچ‌لیست | `36px` (`.pc-watchrow`)، لوگو/پرچم `18px` |
| ردیفِ منو/لیست | `28px` (`.pc-row`)، آیکون `16px` |
| هدرِ سکشن | `28px` (`.pc-section-head`) |
| اینپوتِ درون‌پنل | `28px`؛ اینپوتِ دیالوگ `32px` |
| فونتِ کروم | `12px`؛ محور/لجند/برچسبِ ریز `11px`؛ **کفِ مطلق ۱۱px، اعشاری ممنوع** |
| تیترِ دیالوگ | `14px/600` |

## ۵. تایپوگرافی و اعداد

- هر عددِ قیمتی/درصدی: `.pc-num-ltr` (tabular + جهتِ LTR ایزوله).
- وزن‌ها فقط `400/500/600` (700 فقط قیمتِ بزرگِ هدر).
- هدرِ سکشنِ دوزبانه: فارسی = عنوان (`12px/600`)، انگلیسی = ابروی `10px` uppercase `--pc-text-muted` با `letter-spacing:.4px` — **یک سبک در همهٔ پنل‌ها** (`.pc-section-head`). متن‌ها حذف نمی‌شوند، فقط بازپوشانی.

## ۶. لجند و اوورلی‌های روی چارت

- لجندِ OHLC: **تختِ گوشهٔ بالا-داخل** (RTL: بالا-راستِ ناحیهٔ چارت)، بدونِ حاشیه/پس‌زمینهٔ قرصی؛ `11px`، نامِ نماد `13px/600`. برای خوانایی فقط `text-shadow` یا بک‌دراپِ بسیار ملایم (`backdrop-filter: blur(2px)` + `rgba(bg,.35)` حداکثر).
- چیپ‌های شناور (شمارشِ معکوس، Vol/حجم، replay): تک‌رنگ، مویی، `11px`، بدونِ نقطهٔ قرمز/رنگ.
- واترمارکِ برند: کم‌صدا (حداکثر آلفای `0.06`).
- دکمه‌های گوشهٔ محور (Auto/Log/%): متنِ `11px` muted؛ فعال = متنِ accent. بدونِ قرصِ پر.

## ۷. حرکت

- از توکن‌های موجود: رنگ `--pc-t-color`(60ms)، سطح `--pc-t-surface`(260ms)، منو `--pc-transition-menu`. 
- `transition: all` ممنوع. انیمیشنِ جدید اضافه نکنید.

## ۸. موردهای مشخصِ دیده‌شده در ممیزیِ لایو (باید درست شوند)

1. ردیفِ دائمیِ نقطه‌های رنگیِ پرچم در هدرِ واچ‌لیست → داخلِ پاپ‌اورِ منوی پرچم/⋮ (نمایش on-demand).
2. دکمهٔ AI با گرادیانتِ بنفش → قانونِ §۲.۳.
3. چیپِ TF فعالِ آبیِ پر → تینت+متنِ accent.
4. پیلِ آبیِ `auto` و متنِ `log` پایین-راست → §۶.
5. کارتِ بنفشِ «حقایق کلیدی» → `pc-card-flat`؛ فقط آیکون/عنوانِ کوچک رنگی.
6. پیلِ آبیِ «چارت» در امتیازِ تکنیکال → تبِ متنیِ segmented (فعال: تینت).
7. لجندِ قرصیِ وسط-بالا → §۶.
8. چیپِ شمارشِ معکوس با نقطهٔ قرمز → خنثی.
9. هدرهای سکشنِ ناهمسان (FOREX/DETAILS/KEY FACTS/NEWS/…) → `.pc-section-head` واحد §۵.
10. `--pc-text-muted` باید `var(--text-muted)` شود (AA — الان `#787b86` رد است).

## ۹. قواعدِ اجرا برای ایجنت‌ها

- فقط ظاهر: `className`/`style`/ساختارِ wrapperِ لازم. **هیچ handler/prop/state/متن حذف یا rename نشود.**
- ویرایش‌های کوچکِ دقیق (Edit با old_string یکتا)؛ بازنویسیِ کاملِ فایل ممنوع.
- از کلاس‌های موجودِ `index.css` استفاده کنید: `.pc-toolbar` `.pc-subbar` `.pc-toolbar-sep` `.pc-watchrow` `.pc-section-head` `.pc-row` `.pc-hairline*` `.pc-iconbtn` `.pc-card-flat` `.pc-num-ltr` `.tnum` — به‌جای ساختنِ استایلِ جدید.
- رنگ/اندازهٔ خام (hex، px خارجِ جدول) اضافه نکنید؛ از توکن‌ها (`var(--pc-*)`/`TH.*`) بخوانید.
- RTL: از خواصِ منطقی (`padding-inline`, `margin-inline`, `inset-inline-*`) استفاده کنید.
- بیلد را خودتان اجرا نکنید (تداخل)؛ صحتِ نحوی را با دقتِ ویرایش تضمین کنید.
